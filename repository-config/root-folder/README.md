# Repository Root Folder Configuration

## AI Agents

### Local MCP Servers

Local MCP servers are stored in the `.mcp.json` file in the root repository folder.

#### Rider MCP Server

When a Rider instance is opened, it starts its own MCP Server - the Rider MCP. This folder uses `http://127.0.0.1:64709/stream` which is my current Rider config. It might be different on another machine, so make sure to check the Rider Settings - `Settings | Tools | MCP Server`.
